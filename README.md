# web-xyf · 熊英菲的个人主页

一个用原生 HTML + CSS（加一点点 JavaScript）手写的个人主页，用来记录兴趣、整理作品。

站点由一个**欢迎首页**和三个**独立页面**组成。欢迎页是全屏拼贴插画，点击眼睛图标进入首页内容，再由门户卡片通往三个房间：关于我、我的爱好、我的作品。页面之间用彩色条带擦除转场，每页有自己的主色和场景背景。

## 页面

| 文件 | 内容 |
| --- | --- |
| `index.html` | **欢迎首页**：全屏拼贴欢迎页（珠帘开幕）+ 首屏 + 三个门户入口 + 联系 |
| `about.html` | **关于我**：个人像、自我介绍、兴趣标签 |
| `hobbies.html` | **我的爱好**：阅读（翻页书）/ 听音乐（旋转光盘）/ 心理学 |
| `works.html` | **我的作品**：Pinterest 风格卡片（可展开收起）+ 作品详情 |
| `project1.html` | 作品 01 · 我感兴趣的事情（阅读 / 音乐 / 心理学 / 认知科学） |
| `project2.html` | 作品 02 · 待办事项清单（可增删、标记完成、按分类筛选） |

## 本地预览

直接双击 `index.html` 即可打开。想用本地服务器（推荐，路径和缓存更接近线上）：

```bash
# Python 3
python3 -m http.server 8000

# 或 Node.js
npx serve .
```

然后访问 <http://localhost:8000>。

## 设计说明

- **配色**：深蓝底色（`#0b1d4b`）+ 黄（`#f4d35e`）/ 红（`#ff6b6b`）/ 绿（`#06d6a0`）/ 粉（`#ff85a1`）/ 青（`#4cc9f0`）作为强调色。每个页面有自己的主色（`body.page--*` 里的 `--page-accent`）。
- **场景背景**：每页都有固定的场景层 `.scene`，包含细网格、流动光晕、星尘颗粒和三个漂浮色球，颜色跟随该页主色；在爱好页面悬停卡片时主色会联动变化。
- **页面转场**：点击站内链接时，五条彩色条带自上而下覆盖画面并显示目标页名称，跳转后新页面把条带揭开。
- **翻页器**：每个独立页面底部有「上一站 / 下一站」和三个圆点，形成 关于我 → 我的爱好 → 我的作品 → 关于我 的环。
- **设计变量**：颜色、圆角、阴影集中在 `css/style.css` 顶部的 `:root`，改一处即可整体换风格。
- **响应式**：760px 以下导航收窄为汉堡菜单、首屏竖排、卡片与门户单列。
- **无障碍**：语义化标签、`alt` 文本、跳转链接、键盘焦点样式、`aria-label`，并支持「减少动效」偏好（此时自动跳过转场与逐字动画）。
