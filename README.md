# web-xyf · 熊英菲的个人主页

一个用原生 HTML + CSS（加一点点 JavaScript）手写的个人主页，用来记录兴趣、整理作品。

视觉参考是一张蓝色底色的拼贴插画，所以整体做成了**拼贴 / 剪贴簿风格**：深蓝背景、彩色色块、胶带装饰、手写感标题与微旋转卡片。

## 页面

| 文件 | 内容 |
| --- | --- |
| `index.html` | **欢迎页**：全屏展示拼贴插画，点击眼睛图标进入主页 |
| `home.html` | **主页**：首屏介绍、关于我、作品卡片、作品详情、联系方式 |
| `project1.html` | 作品 01 · 我感兴趣的事情（阅读 / 音乐 / 心理学 / 认知科学） |
| `project2.html` | 作品 02 · 待办事项清单（可增删、标记完成、按分类筛选） |

## 本地预览

直接双击 `index.html` 即可打开。想用本地服务器（推荐，路径和缓存更接近线上）：

```bash
# Python 3
python3 -m http.server 8000

# 或 Node.js
npx serve .
```

然后访问 <http://localhost:8000>。

## 设计说明

- **配色**：浅蓝背景（`#f2f6fc`）+ 靛紫主色（`#4f46e5`）+ 蓝色点缀（`#0ea5e9`）。
- **设计变量**：所有颜色、圆角、阴影集中在 `css/style.css` 顶部的 `:root`，改一处即可整体换风格。
- **响应式**：760px 以下导航收窄、首屏改为竖排、卡片单列；420px 以下隐藏文字 logo。
- **无障碍**：语义化标签、`alt` 文本、跳转链接、键盘焦点样式、`aria-label`，并支持「减少动效」偏好。
